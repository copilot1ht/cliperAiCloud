# Cliper AI Studio V3.4 Pre-Release Audit

Audit date: 2026-07-12
Build target: 1.10.0-beta.3

## Verified

- The reported 51:37 source was re-analyzed from its real cache. The ranking pool was reduced from 699 to 336 candidates and processing time dropped from about 46 seconds to about 31 seconds.
- With no provider-level candidate reaching the evidence gate, the UI receives 14 unique Optional candidates with original/raw scores retained for audit. No score is randomly generated.
- AI selection that returns one clip is now supplemented with non-overlapping Optional candidates instead of ending with one result.
- Highlight metrics use the opening for hook strength, normalize long dialogue windows, and expose raw score, percentile, payoff, retention, filler, and calibration state.
- Audio activity is extracted once at 400 Hz, normalized per source, cached, and blended into dialogue/retention evidence without changing audio.
- Camera analysis on a real source detected three faces and generated 11 hard-cut decisions over 60 seconds across LEFT, CENTER, and RIGHT zones. Maximum measured hold was 5.46 seconds and FFmpeg accepted the crop expression.
- Subtitle timing and word-highlight behavior remain locked. The fixed 32-event ceiling was replaced with a duration-based capacity, while beta.3 adds only subtle letter spacing and safer wrapping.
- A 120-second synthetic word timeline rendered beyond 32 phrases and passed ASS coverage validation; a deliberately truncated ASS failed validation.
- A real 8-second audio-first render produced 19 word events and 19 ASS Caption events with 100% coverage, no validation warnings, valid video/audio streams, and a passing production QA script.
- Quick Editor offline was removed from navigation, HTML, renderer bindings, preload, and Electron IPC. The internal worker reader remains for backward-compatible old payloads only.
- Thirty automated tests pass.
- Custom AI highlight requests use compact story/timeline-balanced batches, module-specific timeout/retry policies, and retain successful batches when another batch fails.
- The provider adapter accepts common OpenAI-compatible response shapes and never silently replaces the model selected by the user.
- Video enhancement samples source luma/chroma, caps normal saturation near +2%, reduces saturation for strong casts, and avoids unmasked channel balancing that could damage skin tones.
- Subtitle captions use subtle resolution-aware letter spacing while preserving the validated word timeline.
- The distribution includes an Indonesian user guide, a tested Python requirements file, and a PowerShell runtime setup helper.
- The beta.3 portable build loaded its renderer from ASAR with five responsive processes and no renderer error. The packaged resources include the guide, requirements file, runtime setup helper, and updated worker.
- A real-source adaptive-filter mini-render produced a valid 720x1280, 3-second YUV420P BT.709 MP4. The full detail pass measured 22.42% overhead and was correctly rejected in favor of integrated-light mode.

## Product Behavior

- Auto selection threshold is 78 and requires an evidence gate. Score 65-77 remains reviewable; lower fallback candidates are visible only as manual Optional results.
- Moment AI presents a compact responsive grid with search, quality filtering, sorting, selection controls, and one review drawer for transcript, metrics, boundaries, preview, accept, and reject.
- Subtitle-enabled render stops with an explicit error when ASS coverage or clip-relative timestamp validation fails after one automatic regeneration attempt.

## Known Limits

- No local heuristic can reliably create polished Indonesian titles from heavily corrupted multilingual auto-captions. The configured AI provider is still required for semantic title rewriting; local fallback titles remain evidence-only to avoid hallucination.
- Visual browser screenshot automation was unavailable in this desktop session. JavaScript syntax, DOM identifiers, Electron launch, and packaged smoke checks are used instead; visual acceptance still requires user review of the beta UI.
- Speaker labels are heuristic when the source has no diarization metadata. Camera zone switching is validated, but identity accuracy depends on transcript/face evidence quality.
- The Windows artifacts do not yet have an Authenticode certificate. They are reproducible and checksummed, but Windows SmartScreen can still warn until a trusted code-signing certificate is configured.
- This audit does not claim 100 full Electron renders, every GPU driver, every network failure, or a defect-free release.

## Decision

Version 1.10.0-beta.3 qualifies as a pre-release test build. Promotion to a stable release should follow user testing on several real YouTube sources with multiple configured Custom AI providers and visual review of camera cuts, subtitle spacing, and the Moment AI grid.
