# Cliper AI Studio V3.3 Pre-Launch Audit

> Superseded by [V3.4_PRE_RELEASE_AUDIT.md](./V3.4_PRE_RELEASE_AUDIT.md).

Audit date: 2026-07-11

## Verified

- Moment AI fallback was reproduced with the 51:37 cached source from the reported failure.
- The same analysis now returns seven visible Optional candidates with unchanged scores from 57 to 67.
- Optional fallback candidates are selectable manually but never auto-rendered; Full Auto remains score 85+.
- Unit coverage passes for highlight scoring, title diversity, subtitle timing, fallback moments, and 4K Look safety.
- A real audio-first QA render produced valid MP4 video and audio streams, 19 word-level subtitle events, and zero caption overlap warnings.
- The production QA script validates output folders, metadata, stream presence, duration, and requested/rendered counts.
- FFmpeg accepts the full adaptive filter chain. The source benchmark rejected it on this machine because measured overhead was 134.65%.
- The active integrated-light profile uses the existing `eq` and `curves` graph, preserves resolution and timing, and adds no separate heavy pass.
- Electron exposes worker cancellation and now terminates an active worker during application shutdown.
- A lightweight component stress run completed 100 sequential and 20 parallel FFmpeg jobs with zero failures using the integrated enhancement graph. This validates the component harness, not 120 full Electron application renders.
- The packaged v1.9.1 ASAR contains the expected UI version, the Python worker is unpacked correctly, and the portable executable launched five responsive processes during smoke testing.

## Known Limits

- The heavy `hqdn3d`, `colorbalance`, `gradfun`, and `unsharp` path is enabled only when a per-source benchmark remains within the 8% safety threshold.
- Speaker diarization and reaction decisions remain heuristic when the source has no reliable speaker metadata.
- The current validation includes one real end-to-end QA render plus automated tests. It is not evidence of 100 full application renders or 20 full renders in parallel.
- Network loss, nearly-full disk, and every GPU driver combination require environment-specific release testing.

## Release Decision

Version 1.9.1 is a validated bug-fix release for the reported Moment AI blank state and the adaptive enhancement path. No claim of zero defects is made; the limits above remain part of the production release notes.
