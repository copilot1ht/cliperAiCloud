CLIPER STUDIO PLUS V3.1 - QA CHECKLIST

Version: 3.1
Date: 2026-07-06

PHASE 1: SUBTITLE SYNC
======================
- Subtitles start 0.14s before speech
- Subtitles snap to sentence boundaries
- Forced alignment support
- Speaker identification from pronouns
- Emotion and importance scoring
- Silent gaps >= 0.3s handled automatically
- Min duration per subtitle: 0.5s

PHASE 2: SPEAKER DETECTION
===========================
- Speaker A/B assignment from transcript
- Hysteresis threshold: MIN_SPEAKER_DURATION = 0.8s
- No rapid camera switching
- Active speaker scoring combining audio+visual
- Speaker switching gap <= 0.5s -> merge ke speaker yang sama

PHASE 3: CAMERA REFRAME
=======================
- Layout selection: SPLIT_SCREEN > FACE_TRACK > BODY_TRACK > CENTER_CROP
- Face tracking with 9:16 crop
- Smooth keyframe transitions
- Stability-based layout validation
- Smooth transitions (jitter reduction)
- Jangan flip speaker tiba-tiba tanpa hysteresis

PHASE 4: SPLIT SCREEN
=====================
- Minimum overlap duration: 0.7s
- Layout detection: LEFT_RIGHT, TOP_BOTTOM, GRID_3, SINGLE
- Multi-speaker frame allocation
- Active speaker focus
- Jangan split jika overlap < threshold

PHASE 5: HIGHLIGHT AI
=====================
- Scoring with weighted factors (hook, emotion, payoff, story, etc.)
- Penalty system: too_silent(-20), too_short(-10), no_payoff(-15)
- Multi-face confidence boost
- Real engagement predictor
- engagement_score + (speaker_density * 10) - penalties
- Min duration highlight: 3s
- Max overlap 25% antar highlight

END-TO-END TESTS
================
- YouTube video download with/without cookies
- Subtitle extraction (auto + manual)
- Local video upload and processing
- Moment ranking and selection
- FFmpeg rendering with GPU detection
- Output validation (MP4, duration, audio presence)
- Metadata JSON generation

SPECIFIC VALIDATION
===================
- Subtitles sync within 0.2s of speech (jitter <= 0.1s)
- Camera doesn't switch < 0.8s (hysteresis works)
- Split screen only triggers with >= 0.7s overlap
- Scoring doesn't exceed 99 or drop below 35
- No duplicate clips in output
- FFmpeg render completes without errors

OUTPUT VALIDATION
=================
For each rendered clip:
- MP4 file exists and playable
- Duration matches requested (plus/minus 0.5s)
- Audio stream present
- Subtitles burned correctly
- Metadata JSON valid

ERROR HANDLING
==============

- Cookie required -> prompt user

- Disk space full -> clear cache

SECURITY
